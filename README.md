# React JS Calculator

A clean, responsive calculator application built with React, featuring a tactile physical-calculator card aesthetic and intuitive color-coded button groupings.

**Live Demo:** [View Live](https://react-js-calculator-demo.vercel.app/)

## Features
- **Core Arithmetic Operations:** Supports addition, subtraction, multiplication, division, and percentage calculations.
- **State & Input Controls:** Dedicated `C` (All Clear) and `DEL` (Backspace) actions for smooth expression editing.
- **Visual Hierarchy:** Color-coded utility, operator, and numeric keys paired with a high-contrast digital display.

## Tech Stack
- React (Functional Components & Hooks)
- CSS Grid / Flexbox
- Deployed on Vercel
